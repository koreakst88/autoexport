# Яндекс.Метрика

Production-счётчик `113573960` подключён на `https://koredigital.co.kr`. Включены Webvisor, карта кликов, отслеживание внешних ссылок, точный показатель отказов и контейнер электронной коммерции `dataLayer` (передача e-commerce событий пока не используется на лендинге).

## Цели для настройки в интерфейсе счётчика

Создать JavaScript-события с точным совпадением идентификаторов:

| Идентификатор | Что фиксируется | Роль |
| --- | --- | --- |
| `lead_draft_requested` | Валидная заявка, после которой открывается Telegram-черновик | Основная цель для Директа |
| `lead_form_start` | Первое взаимодействие с полем заявки за визит | Воронка, вспомогательная |
| `telegram_contact_open` | Нажатие на верхнюю кнопку связи в Telegram | Цель обращения |
| `web_demo_open` | Открытие веб-демо AutoExport | Интерес к демо |
| `product_telegram_open` | Открытие Telegram-продукта из карточки | Интерес к продуктам |

События не содержат значения полей формы. Поля компании и описания задачи помечены `ym-disable-keys`, чтобы Webvisor маскировал ввод. Лендинг не отправляет поля на свой сервер: форма открывает текстовый черновик в Telegram.

В production ID хранится как публичная переменная окружения `NEXT_PUBLIC_YANDEX_METRIKA_ID`; без ID счётчик не запускается. Для локальной работы можно задать этот ID в `.env.local`.

Настройки Webvisor, включая запись ввода всех полей, следует сверить в интерфейсе счётчика. Содержимое компании и описания задачи не должно отображаться в записях.
