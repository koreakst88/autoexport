# Этап 4 — форма обращения

Форма в контактном блоке помогает автодилеру выбрать направление разработки и кратко описать задачу.

- Поля: направление (обязательно), компания (необязательно), описание задачи (обязательно).
- Получатель: Telegram `@koreakim88`, совпадает с ранее указанным контактным CTA.
- При отправке открывается новый Telegram-черновик с выбранными данными. Посетитель проверяет сообщение и нажимает «Отправить» самостоятельно.
- Лендинг не делает сетевой запрос с содержимым формы и не хранит введённые значения.
- Это передача черновика, а не серверная отправка заявки; для автоматического приёма, CRM или уведомлений нужен отдельный согласованный способ интеграции.

Проверка: `npm run typecheck`, `npm run build`, визуальный просмотр на десктопе и мобильной ширине.
